BAYESIAN GAMMA TIMING MODEL - Implementation Instructions
=========================================================

Goal: Implement TRUE Bayesian sequential updating for the Gamma timing model
- Use PyMC for MCMC sampling (not MLE)
- Store posterior samples from previous fits
- Use previous posterior as informative prior for next fit
- Proper Bayesian credible intervals from posterior samples

Key Difference from Factored Gamma Model:
- Factored: MLE + bootstrap (frequentist, refits from scratch)
- Bayesian: MCMC + sequential updating (posterior → prior chaining)

[X] 1. CORE BAYESIAN FITTER (bayesian_gamma_fitter.py) ✓ COMPLETE

    Purpose: Fit Gamma(α, β) using PyMC MCMC, support sequential updating

    Key Methods:
    - fit_initial(times, cdf_values) → posterior samples
        * First fit: use weakly informative priors
        * Sample from implied PDF (like MLE version)
        * PyMC model: α ~ HalfNormal(5, 3), β ~ HalfNormal(1, 2)
        * NUTS sampling: 500 draws × 2 chains
        * Return: InferenceData with posterior samples

    - fit_sequential(times, cdf_values, prior_samples) → posterior samples
        * Sequential fit: use previous posterior as new prior
        * Approximate prior from samples (kernel density or parametric fit)
        * Use as informative prior for α, β
        * NUTS sampling on new data
        * Return: InferenceData with updated posterior

    - predict_cdf(times, posterior_samples) → Dict[lower, upper, median]
        * For each posterior sample: compute Gamma CDF
        * Return percentiles across posterior predictive samples

    Implementation Details:
    - Use pymc.sample_prior_predictive() to sample from implied PDF
    - Likelihood: compare predicted CDF to observed CDF (Normal error)
    - Store trace as arviz InferenceData
    - For sequential: fit Normal/Gamma to previous α, β samples as prior

PyMC Model Structure:
```python
with pm.Model() as model:
    # Priors (informative if sequential, weakly informative if initial)
    alpha = pm.HalfNormal('alpha', mu=alpha_prior_mu, sigma=alpha_prior_sigma)
    beta = pm.HalfNormal('beta', mu=beta_prior_mu, sigma=beta_prior_sigma)

    # Likelihood: fit to implied samples from CDF
    # Sample from PDF, then fit Gamma likelihood
    pm.Gamma('obs', alpha=alpha, beta=beta, observed=sample_times)

    # Or alternative: fit CDF directly with Normal error
    # predicted_cdf = pm_gamma_cdf(times, alpha, beta)
    # pm.Normal('cdf_obs', mu=predicted_cdf, sigma=0.05, observed=cdf_values)

    # Sample
    idata = pm.sample(draws=500, tune=500, chains=2, target_accept=0.95)
```

Sequential Prior Construction:
```python
# Extract previous posterior samples
prev_alpha = idata.posterior['alpha'].values.flatten()
prev_beta = idata.posterior['beta'].values.flatten()

# Fit parametric distribution (e.g., LogNormal)
alpha_prior_mu = np.log(np.mean(prev_alpha))
alpha_prior_sigma = np.std(np.log(prev_alpha))

beta_prior_mu = np.log(np.mean(prev_beta))
beta_prior_sigma = np.std(np.log(prev_beta))

# Use as informative prior in next fit
```

Performance Considerations:
- MCMC is slower than MLE (500 draws vs instant)
- Use Haiku model for fitting if speed critical
- Cache posteriors to avoid redundant computation
- Only refit when data changes significantly

Expected Benefits:
- More realistic uncertainty quantification
- Narrowing CI as event approaches (learning)
- Better calibrated predictions
- Principled incorporation of previous information

Expected Costs:
- Slower fitting (MCMC vs MLE)
- More complex codebase
- Storage overhead (posterior samples)
- Potential convergence issues
